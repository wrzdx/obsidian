# Как пользоваться хранилищем

Начинай с [[Главная|главной страницы]].

## Где что лежит

| Раздел | Что туда складывать |
| --- | --- |
| Входящие | Новые записи, которым ещё нужно выбрать место. |
| Знания | Конспекты, понятия, учебные материалы и оглавления тем. |
| Проекты | Идеи, отчёты и материалы конкретных проектов. |
| Личное | Мысли, документы, поездки и личные планы. |
| Library | Изображения, PDF, видео и другие вложения. |

## Новая заметка

1. Нажми **Ctrl+N**: заметка появится во «Входящих».
2. Дай ей название, которое понятно без открытого оглавления: «Архитектура компьютера — лабораторная 2», а не просто «Lab 2».
3. Когда место понятно, перенеси её в нужный раздел и добавь ссылку из оглавления темы.

Даты нужны для дневниковых записей: `2026-04-10 — Мысли`. Название понятия можно оставить на английском. Альтернативные имена помогают находить переименованные заметки по прежним названиям.

Для внутренней ссылки набери `[[` и выбери заметку. Для подписи используй `[[Знания/Базы данных|Базы данных]]`. Ctrl+K вставляет обычную Markdown-ссылку. При переименовании в Obsidian включено автоматическое обновление ссылок.

Обязательных тегов и свойств нет. Существующие учебные теги сохранены. Раз в неделю выдели 10 минут на входящие: уточни название, выбери место, добавь ссылку в оглавление.

## Сочетания клавиш

| Клавиши | Действие |
| --- | --- |
| Ctrl+O | Найти и открыть заметку. |
| Ctrl+P | Найти команду Obsidian или плагина. |
| Ctrl+G | Открыть граф связей. |
| Ctrl+Enter | Перейти по ссылке под курсором; отсутствующая заметка может быть создана. |
| Alt+0 / Alt+1…6 | Обычный текст / заголовок указанного уровня. |
| Alt+F | Note Refactor: выделенный текст → отдельная заметка, первая строка становится названием. |
| Ctrl+] | Извлечь раздел под заголовком в отдельную заметку. |
| Ctrl+[ | Извлечь выделенный текст в отдельную заметку. |
| Ctrl+Shift+= | Git: создать коммит всех изменений. |
| Ctrl+Shift+- | Git: отправить коммиты. |
| Ctrl+Shift+H | Найти и заменить текст внутри выделенного фрагмента. |
| Alt+- / Alt+= | Вставить нумерованную / именованную сноску. |
| Alt+E | Полноэкранный режим Excalidraw. |
| Ctrl+Shift+B | Вставить шаблон из папки templates. |
| Ctrl+Enter при выборе подсказки Completr | Вставить выбранную подсказку. |

Сочетания записаны по твоим настройкам. Ctrl+Enter имеет несколько назначений: результат зависит от того, открыт ли список подсказок Completr.

Alt+F, Ctrl+], Ctrl+[ и переход по отсутствующей ссылке могут создавать новые заметки. Это возможный источник случайных файлов; определить происхождение уже созданного файла по его содержимому нельзя. Новые заметки Note Refactor теперь тоже попадают во «Входящие».

## Callout и шаблоны

Добавь `+` или `-` после типа callout, чтобы сделать его сворачиваемым: `[!note]+` или `[!note]-`.

В templates сохранены два коротких шаблона: `break line` — перенос строки, `break page` — разрыв страницы для экспорта. Они намеренно короткие.

## Обмен между компьютерами

Перед переходом на другой компьютер выполни через Ctrl+P **Git: Commit-and-sync**. На втором устройстве — **Git: Pull**. Пока Obsidian открыт, обмен выполняется автоматически раз в 5 минут; скачивание также включено при запуске.
