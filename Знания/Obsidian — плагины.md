# Мои плагины

На момент уборки установлено **19 сторонних плагинов: 14 включены, 5 выключены**. Статус взят из твоего `community-plugins.json`, назначения — из описаний установленных версий. Набор включённых плагинов сохранён.

## Включены

| Плагин | Для чего нужен |
| --- | --- |
| Git | Коммиты, скачивание и отправка заметок через GitHub; у тебя обмен раз в 5 минут. |
| Excalidraw | Рисунки от руки, схемы и визуальные конспекты прямо в хранилище. |
| Advanced Tables | Удобное редактирование и выравнивание Markdown-таблиц. |
| Quick Latex | Быстрый ввод формул: сокращения, дроби, матрицы и выравнивание. |
| Completr | Подсказки и автодополнение слов, LaTeX-команд и свойств заметки. |
| Note Refactor | Выделить часть конспекта в новую заметку или разделить длинную заметку на несколько. У тебя извлечение по первой строке назначено на Alt+F. |
| Footnote Shortcut | Быстро вставлять и редактировать сноски; Alt+- и Alt+=. |
| Find & Replace in Selection | Искать и заменять текст только в выделенном фрагменте; Ctrl+Shift+H. |
| Code Styler | Настраивать внешний вид блоков кода и коротких фрагментов кода в строке. |
| Columns | Размещать содержимое заметки в нескольких колонках. |
| Style Settings | Менять параметры оформления, которые предоставляют тема, плагины и CSS-сниппеты. |
| Smart Typography | Автоматически заменять обычные кавычки, дефисы и точки на типографские символы. |
| Emoji Toolbar | Искать и вставлять эмодзи. |
| Scroll Speed | Настраивать скорость прокрутки заметок. |

## Что может создавать новые файлы

- **Note Refactor** создаёт отдельные заметки из выделения или заголовков. Описание команды должно соответствовать тому, что ты хочешь извлечь.
- **Excalidraw** создаёт файлы рисунков `.excalidraw.md`. Такие файлы могут быть полезными, даже если выглядят как технический текст. При уборке удалён только проверенный рисунок без элементов и изображений.
- Встроенный **Bases** создаёт файлы `.base` для табличных представлений заметок. Это встроенная функция, отдельного стороннего плагина Bases у тебя нет.
- Встроенные **Daily notes** создают заметку на выбранную дату, а **Note composer** извлекает фрагмент или раздел в новый файл.
- Переход по ссылке на отсутствующую заметку также может создать новый файл.

Completr и Quick Latex оба помогают при вводе формул: первый предлагает продолжение, второй ускоряет набор сокращениями. Style Settings управляет предоставленными параметрами оформления, а Minimal Theme Settings относится именно к теме Minimal.

## Встроенные функции, которые уже включены

Поиск и переключатель заметок, обратные ссылки, граф, панель тегов, оглавление текущей заметки, закладки, шаблоны, ежедневные заметки, Note composer, Canvas, Bases и восстановление файлов. Платный Obsidian Sync выключен: для обмена используется Git.

## Старые назначения клавиш

В настройках оставались команды отсутствующих плагинов Homepage, Templater, Better Internal Link Inserter и Hotkeys++. Их назначения удалены. В частности, прежнее Ctrl+Shift+K относилось к отсутствующему Better Internal Link Inserter: для ссылки теперь достаточно набрать `[[` и выбрать заметку.

Сохранено действующее Ctrl+Shift+H для поиска и замены в выделении; удалена старая дублирующая запись этой команды с другим идентификатором.
